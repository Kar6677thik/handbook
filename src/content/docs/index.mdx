## How to trust a page

<CardGrid>
	<Card title="Check the bar under the title" icon="information">
		Each page names an **owner** and the date someone last **verified** it against the real system. A page that is **stale** or **never verified** may be wrong.
	</Card>
	<Card title="Fix it when it's wrong" icon="pencil">
		If a page doesn't match reality, correct it in the same sitting. Update the `lastVerified` date when you do. See [Writing docs](/start-here/writing-docs/).
	</Card>
</CardGrid>
